# AOSP notification sounds

ToastDesk v2 bundles eight converted AOSP notification tones (Apache 2.0).

- Source: Android Open Source Project `platform/frameworks/base` `data/sounds/notifications/ogg`
- https://android.googlesource.com/platform/frameworks/base/+/refs/heads/main/data/sounds/notifications/ogg/
- License: https://source.android.com/license

Original files are OGG. These copies are mono WAV for Windows `PlaySoundW`.

Presets: Acrux, Adara, Altair, Alya, Antares, Argon (default), Capella, Vega.
