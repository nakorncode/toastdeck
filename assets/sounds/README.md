# Bundled Notification Sounds

These preset WAV files come from two sources.

## OpenCode Notifier Sounds

Files prefixed with `opencode-` come from `@mohak34/opencode-notifier`.

Source: https://www.npmjs.com/package/@mohak34/opencode-notifier

License: MIT

## Subtle Notification Sounds

Other preset WAV files come from `akx/Notifications`.

Source: https://github.com/akx/Notifications

License options from the source project:

- CC Attribution 3.0 Unported
- CC0 Public Domain

ToastDesk uses these files as production-safe preset notification sounds. Do not bundle third-party game audio from OpenCode notifier examples unless licensing is explicitly cleared.
